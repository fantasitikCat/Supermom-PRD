Design principles 设计原则

P1
Events = user actions 事件 = 用户行为

Event names answer: what did the user do? Verb + noun, no business unit encoding.事件名只描述用户做了什么，不编码业务单元。

P2
Parameters = context 参数 = 上下文

Parameters answer: what was the user acting on?参数描述用户对什么进行了操作，在什么场景下。

P3
One event name per action 同类行为只有一个事件名

Use parameters to distinguish context. Never create per-unit event names.用参数区分业务，禁止为每个业务单元创建独立事件名。

P4
Page ≠ Component 页面 ≠ 组件

AIMA and QA are components on a page, not page types.AIMA 和 QA 是页面上的组件，不是页面类型。

Naming — avoid vs use 命名规范

❌ Avoid 禁止
banner_clickcampaign_clicksearch_click
✓ Use 正确写法
content_click + component_type: "banner"content_click + component_type: "campaign_list"search_result_click

04

Conditional field rules 条件必填规则

When a field is marked CONDITIONAL, its requirement depends on the value of content_type.字段标记为 CONDITIONAL 时，是否必填取决于 content_type 的值。

Conditional Required Rules — 条件必填规则
If content_type = "article" → content_id Required · content_category Required文章：content_id 和 content_category 必填
If content_type = "flashcard" → content_id Required闪卡：content_id 必填
If content_type = "lead_gen" / "survey" / "ugc" / "referral" → content_id Required · form_id Required on form pages活动类型：content_id 必填；表单页时 form_id 必填
If content_type = "community_group" → content_id Required社群：content_id 必填
If content_type = "event" → content_id Required · source_system Required · content_source Required外部活动：content_id、source_system、content_source 均必填
If content_type = "external_link" → link_url Required · link_domain Recommended外部链接：link_url 必填，link_domain 推荐填写
If page_type = "detail" or "listing" → content_type Required详情页或列表页：content_type 必填
If component_type has position concept ("banner" / "recommendation_widget" / "article_list" / "campaign_list" / "group_list" / "carousel") → impression_position Required in content_impression · clicked_position Required in corresponding content_click有位置概念的组件：impression_position 必填，对应 content_click 中 clicked_position 必填
If component_type = "recommendation_widget" → recommendation_source Required推荐组件：recommendation_source 必填
If page has active filter state and event is content_impression or content_click → all active filter_* fields Required: filter_life_stage on /guide · filter_content_category on /guide article section · filter_group_type on /connect · filter_audience on /giveaway有过滤器的列表页，content_impression 和 content_click 必须携带所有当前激活的 filter_* 字段；前端需维护 filter 状态对象
If button_action_type = "switch_tab" → tab_value Required — used only on /earn for content type switching/earn 内容类型 Tab 切换：tab_value 必填
If page_type = "listing" and page is /earn → tab_value Required in page_view to record initial Tab state/earn 页 page_view：tab_value 必填，记录初始 Tab 状态，默认值 all
If event is otp_popup_view → source_component Required · source_page Required · component_name RequiredOTP 弹窗触发：source_component、source_page、component_name 三字段均必填
source_campaign_id vs campaign_id： source_campaign_id = the campaign the user is currently on（当前所在活动，即上下文）. campaign_id = the campaign being displayed as content（被展示的内容活动）.例：用户在活动 A 的 thank_you 页（source_campaign_id: "cmp_001"），看到推荐的活动 B（campaign_id: "cmp_002"）。
