Signal 是什么 What Is a SignalWhat Is a Signal

中文
Signal 是系统对用户行为 / 内容 / 属性的业务理解，是介于原始事件和最终 tag 之间的语义理解层。Signal 跨数据源、相对稳定，不与平台强绑定。同一种 signal 可以由 Pulse、AIMA 或 GA4 不同来源产生，V2 统一接收并生成最终 tag。
English
A Signal is the system's semantic understanding of a user's behavior, content, or attribute. It sits between raw events and final tags as the Semantic Understanding Layer. Signals are source-agnostic and cross-platform stable — the same signal can be produced by Pulse, AIMA, or GA4. V2 normalizes all sources before generating tags.

数据链路 Data PipelineData Pipeline

各系统独立运行，输出同一套 signal 格式，V2 是统一的 tag 执行层。 Each data source runs independently and outputs signals in the same unified format. V2 is the single tag execution layer.
Phase 1 原则：不做 confidence 计算（CF001–CF006）。Tag 生成是确定性的——词典命中 + signal_count 达到阈值 = tag 立即生效，无概率判断。 Phase 1 principle: No confidence scoring (CF001–CF006). Tag generation is deterministic — keyword match + signal_count threshold met = tag fires immediately. No probability calculation.

Real behavioral events — article clicks, video plays, purchases. Actual on-platform actions.

高可信度High reliability

Purchase history and spending behavior. Strong indicator of affluence and product affinity.
AIMA
中等可信度Medium reliability

1:1 conversation topics and intent. LLM-extracted — contextual but needs validation.
Form Answers
中等可信度Medium reliability
用户主动填写数据，意图强，频率低。
Explicit self-reported data. High intent signal, lower frequency.
Pulse
较低可信度Lower reliability
群聊关键词匹配，信号宽泛，意图较弱，适合大规模兴趣发现。
Group chat keyword matches. Broad signal, weaker intent. Useful for interest discovery at scale.
