01

Design principles 设计原则

P1
Events = user actions 事件 = 用户行为

Event names answer: what did the user do? Verb + noun, no business unit encoding.事件名只描述用户做了什么，不编码业务单元。

P2
Parameters = context 参数 = 上下文

Parameters answer: what was the user acting on?参数描述用户对什么进行了操作，在什么场景下。

P3
One event name per action 同类行为只有一个事件名

Use parameters to distinguish context. Never create per-unit event names.用参数区分业务，禁止为每个业务单元创建独立事件名。

P4
Page ≠ Component 页面 ≠ 组件

AIMA and QA are components on a page, not page types.AIMA 和 QA 是页面上的组件，不是页面类型。

Naming — avoid vs use 命名规范

❌ Avoid 禁止
banner_clickcampaign_clicksearch_click
✓ Use 正确写法
content_click + component_type: "banner"content_click + component_type: "campaign_list"search_result_click

Conditional field rules 条件必填规则

When a field is marked CONDITIONAL, its requirement depends on the value of content_type.字段标记为 CONDITIONAL 时，是否必填取决于 content_type 的值。

Conditional Required Rules — 条件必填规则
If content_type = "campaign" → campaign_id Required · campaign_type Required内容类型为活动时：campaign_id 和 campaign_type 必填
If content_type = "article" → content_id Required · content_category Required内容类型为文章时：content_id 和 content_category 必填
If content_type = "qa" → content_id Required · content_category Recommended内容类型为 QA 时：content_id 必填，content_category 推荐填写
If content_type = "group" → content_id Required · content_category Required内容类型为社群时：content_id 和 content_category 必填
If content_type = "external_link" → link_url Required · link_domain Recommended内容类型为外部链接时：link_url 必填，link_domain 推荐填写
source_campaign_id vs campaign_id： source_campaign_id = the campaign the user is currently on（当前所在活动，即上下文）. campaign_id = the campaign being displayed as content（被展示的内容活动）.例：用户在活动 A 的 thank_you 页（source_campaign_id: "cmp_001"），看到推荐的活动 B（campaign_id: "cmp_002"）。

08

Attribution & UTM 归因与 UTM

acq_* vs utm_* — 两套归因体系并行，互不替代 utm_*（本文档）：前端 session-level 归因，存入 GA4 → BigQuery tracking 层，每次新 session 可覆盖，由 GTM 负责。
acq_*（见 → Landing Page Attribution PRD 和 acq_* 字段说明）：后端 First-touch 归因，只记录用户首次进入 Landing Page 时的来源，存入业务数据库，不覆盖，由 Backend 负责。
两套体系通过 v2_uid 在 BigQuery 中关联。acq_* 字段不得出现在 dataLayer 中。 Key alignment: acq_source: "aima_bot" maps to utm_source: "aima". Always use utm_source: "aima" in tracking contract — never aima_bot.

UTM persistence rule UTM 持久化规则
