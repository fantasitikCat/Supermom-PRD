GTM E-commerce Configuration Guide

Step-by-step GTM setup to transform custom dataLayer events into GA4 standard e-commerce events. Enables the GA4 built-in Purchase Journey funnel report without changing any frontend code. 将自定义 dataLayer 事件转换为 GA4 标准电商事件，无需修改前端代码即可启用 GA4 内置漏斗报告。

§1

Architecture 架构说明

Frontend pushes one event to dataLayer. GTM reads it and fires two GA4 events: the custom event (for BigQuery analysis) and a standard e-commerce event (for GA4 built-in reports). The frontend never pushes e-commerce events directly.

Frontend dataLayer          GTM                    GA4
──────────────────          ───                    ───
content_impression    ───►  Tag A ──► content_impression  (BigQuery)
                      ───►  Tag B ──► view_item_list       (E-commerce funnel)

content_click         ───►  Tag A ──► content_click        (BigQuery)
                      ───►  Tag B ──► select_item           (E-commerce funnel)

content_view          ───►  Tag A ──► content_view         (BigQuery)
                      ───►  Tag B ──► view_item             (E-commerce funnel)

begin_checkout        ───►  Tag A ──► begin_checkout        (BigQuery + GA4 funnel)

purchase              ───►  Tag A ──► purchase              (BigQuery + GA4 funnel)
event_id is the link. Both Tag A and Tag B read event_id from the same dataLayer push. In BigQuery you can join content_impression with view_item_list using event_id to verify the mapping is correct.

Step 1 — Create Data Layer Variables 第一步：创建数据层变量

Variables are GTM's way of reading values from the dataLayer. Create all variables below before configuring any Tags. Each variable maps a dataLayer key to a GTM variable name you can reference in Tags.

Where to find this in GTM: Left sidebar → Variables → User-Defined Variables section → New.GTM 左侧导航 → Variables → User-Defined Variables → New。

How to create one variable — step by step

1
Variables → New
Click New in the top right of the User-Defined Variables section.
2
Variable Configuration → choose Data Layer Variable
Click Variable Configuration → scroll to Page Variables → select Data Layer Variable.
3
Set Data Layer Variable Name
In the Data Layer Variable Name field, enter the key exactly as it appears in the dataLayer (e.g. event_id).

Set Data Layer Version to Version 2.

Leave Default Value empty unless specified below.
4
Name the variable
In the top left name field, enter the GTM Variable Name from the table below (e.g. DLV - event_id). Click Save.

Step 3 — Tag: view_item_list 第三步：配置 view_item_list Tag

This Tag fires every time a content card enters the viewport. It converts content_impression into GA4's standard view_item_list e-commerce event.

Create the Tag

1
Tags → New
Left sidebar → Tags → New. Name the tag: GA4 - view_item_list.
2
Tag Configuration → Custom HTML
Click Tag Configuration → under Custom → select Custom HTML.

Use Custom HTML instead of the GA4 Event tag type because GA4 Event tags do not support nested items arrays natively. Custom HTML gives full control over the payload structure.
3
Paste the HTML code
Paste the code below into the HTML field. Replace G-XXXXXXXXXX with your GA4 Measurement ID.
<script>
window.gtag('event', 'view_item_list', {
  send_to: 'G-XXXXXXXXXX',
  event_id:       {{DLV - event_id}},
  item_list_name: {{DLV - component_type}},
  items: [{
    item_id:        {{DLV - content_id}},
    item_name:      {{DLV - content_id}},
    item_category:  {{DLV - content_type}},
    item_category2: {{DLV - content_category}},
    item_category3: {{DLV - filter_audience}} || {{DLV - filter_life_stage}} || {{DLV - filter_group_type}} || {{DLV - tab_value}},
    item_category4: {{DLV - filter_content_category}},
    item_list_id:   {{DLV - recommendation_source}},
    index:          {{DLV - impression_position}}
  }]
});
</script>
4
Set Triggering
Scroll down to Triggering → click the + icon → select CE - content_impression.

Click Save.

Step 7 — Tag: purchase 第七步：配置 purchase Tag

transaction_id is mandatory. GA4 uses it to deduplicate purchase events. Always map it — a missing transaction_id causes duplicate conversions counted in GA4.transaction_id 必填。GA4 用它去重转化事件。切勿遗漏，否则 GA4 里会重复计算转化。

Create the Tag

1
Tags → New → Custom HTML
Name: GA4 - purchase. Paste code below.
2
Set Triggering → CE - purchase
Triggering → CE - purchase. Save.
<script>
window.gtag('event', 'purchase', {
  send_to: 'G-XXXXXXXXXX',
  event_id:       {{DLV - event_id}},
  transaction_id: {{DLV - transaction_id}},  // from Backend — mandatory
  value:          0,
  currency:       'SGD',
  items: [{
    item_id:       {{DLV - content_id}},
    item_name:     {{DLV - content_id}},
    item_category: {{DLV - content_type}}
  }]
});
</script>
