About this document 关于本文档

This document contains only the official allowed values (enums) for each field. To understand when and how to use these fields, refer to the Tracking Master PRD. 本文档只包含每个字段的官方合法值（枚举）。要了解何时、如何使用这些字段，请参阅《Tracking Master PRD》。

For AI tools / 给 AI 工具： This document is a lookup table. Every section follows: field name → allowed values table. Values not listed here are not permitted. 本文档是查找表。每节结构：字段名 → 合法值表。未在本文档列出的值不允许使用。

§1

page_type 页面类型

Describes the structural template of the page — not what content is on it. Content type is described by content_type. 描述页面的结构模板，不描述页面上的内容类型。内容类型由 content_type 字段承担。

Design rule / 设计原则： page_type values must be stable across product changes. Adding a new content type must never require adding a new page_type value — add a content_type value instead.page_type 枚举值应保持稳定。新增内容品类时只需新增 content_type 值，无需修改 page_type。

component_type 组件类型

Represents the UI component the user is interacting with.表示用户当前正在交互的 UI 组件。

§3

§6

source_system / content_source 外部系统来源标识

NEW Used when content_type = "event" to identify which external system the content originates from. Owner: Backend.当 content_type 为 event 时，标识内容来自哪个外部系统。由后端 API 返回，前端透传。

source_system = the aggregation platform entry point（数据入口平台）. content_source = the original system that created the event（活动的原始创建系统）. Both fields are provided by the backend API response — frontend passes them through transparently.两个字段均由后端 API 响应提供，前端直接透传，不需要前端判断。

Prerequisite / 前提： The event platform API must return content_source in its response. Confirm with the event platform team that this field is available before implementation.实施前需确认 event_platform API 响应中已包含 content_source 字段。

§15

filter_value 过滤条件值

NEW The value selected by the user in a filter_widget. Sent in button_click events when button_action_type = "apply_filter".用户在过滤组件中选择的筛选条件值。在 button_action_type 为 apply_filter 的 button_click 事件中携带。

GA4 exposure rule： filter_value is high-cardinality. Do NOT register as a GA4 Custom Dimension. Use BigQuery only.filter_value 为高基数字段，禁止注册为 GA4 自定义维度，仅在 BigQuery 中分析。

Values are free-form strings representing the filter label. Examples by page:值为自由字符串，代表筛选标签。各页示例：

Page 页面Example filter_value values
