About this document 关于本文档

This document contains only the official allowed values (enums) for each field. To understand when and how to use these fields, refer to the Tracking Master PRD. 本文档只包含每个字段的官方合法值（枚举）。要了解何时、如何使用这些字段，请参阅《Tracking Master PRD》。

For AI tools / 给 AI 工具： This document is a lookup table. Every section follows: field name → allowed values table. Values not listed here are not permitted. 本文档是查找表。每节结构：字段名 → 合法值表。未在本文档列出的值不允许使用。

§1

page_type 页面类型

Describes the structural template of the page — not what content is on it. Content type is described by content_type. 描述页面的结构模板，不描述页面上的内容类型。内容类型由 content_type 字段承担。

§13

source_component + source_page OTP 触发意图 + 来源页面

Two fields used together to fully identify the OTP trigger context. Always push both fields together in OTP and registration flow events.两个字段配合使用，完整标识 OTP 触发上下文。在 OTP 和注册流程事件中始终同时推送。

Design rule / 设计原则： source_component = what the user was trying to do. source_page = which page it happened on. Splitting into two fields means new pages never require new source_component enum values. source_component 描述用户意图，source_page 描述发生页面。拆分为两个字段后，新增页面不需要新增 source_component 枚举值。
BQ derived field / BQ 派生字段： trigger_type (proactive vs intercepted) — derive in BigQuery:

CASE WHEN source_component = 'navigation_register' THEN 'proactive' ELSE 'intercepted' END AS trigger_type 主动注册 vs 被拦截不需要前端推送，在 BigQuery 中用 CASE 派生。新增枚举值时同步更新此 CASE。

§15

Filter fields 过滤字段

Each filter dimension has its own dedicated field. Always carry active filter state in content_impression and content_click events on filtered listing pages.每个过滤维度有独立字段。在有过滤器的列表页，content_impression 和 content_click 事件必须携带当前激活的过滤状态。

Design rule / 设计原则： Filter fields describe UI state, not content attributes. content_category = what the content is. filter_content_category = what the user selected. They are independent and both required when applicable.过滤字段描述 UI 状态，不描述内容属性。content_category 是内容本身的分类，filter_content_category 是用户选择的过滤条件，两者独立，各自必填。
GA4 exposure rule： All filter fields are high-cardinality. Do NOT register as GA4 Custom Dimensions. Use BigQuery only.所有过滤字段均为高基数，禁止注册为 GA4 自定义维度，仅在 BigQuery 中分析。
