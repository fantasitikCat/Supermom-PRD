About this document 关于本文档

This document contains only the official allowed values (enums) for each field. To understand when and how to use these fields, refer to the Tracking Master PRD. 本文档只包含每个字段的官方合法值（枚举）。要了解何时、如何使用这些字段，请参阅《Tracking Master PRD》。

For AI tools / 给 AI 工具： This document is a lookup table. Every section follows: field name → allowed values table. Values not listed here are not permitted. 本文档是查找表。每节结构：字段名 → 合法值表。未在本文档列出的值不允许使用。

§4

content_category 内容分类

The topic category of the content. Applies consistently to articles, campaigns, QA, groups, and recommendations. Owner: CMS.内容所属主题分类，统一适用于文章、活动、QA、社群和推荐内容。由 CMS 在内容发布时设置。

§4b

content_format 内容呈现形式

Describes how the content is presented, not what it is. Used alongside content_type. Owner: CMS.描述内容的呈现形式，而非内容实体类型。与 content_type 配合使用。例：content_type: "article" + content_format: "video" = 视频形式的文章内容。

Value 值Chinese 中文Description 说明
article图文Default text + image format默认图文形式
video视频Video-first or video-only content视频为主或纯视频内容
mixed图文 + 视频Text article with embedded video文章内嵌视频
interactive互动内容Polls, quizzes, interactive Q&A投票、测试、互动问答
§4c · Definition #1

content_format selection rule — campaign 活动页面的 content_format 选择规则

When content_type is "campaign", the value of content_format shall be determined by the structural composition of the campaign page. 当 content_type 为 "campaign" 时，content_format 的取值由活动页面的内容构成决定。

Page composition 页面构成content_typecontent_formatRationale 判断依据
Rich text / images + embedded form
图文介绍 + 内嵌表单		 campaign mixed Page contains both editorial content and an interactive form element. Neither dominates exclusively.页面同时包含图文内容和表单交互，两者并存。
Form only — no editorial content
纯表单，无图文内容		 campaign interactive The sole user interaction is form input and submission. No editorial content is consumed.用户唯一的操作是填写和提交表单，页面不包含可消费的图文内容。
Owner / 负责人： CMS — this value shall be assigned at the time of campaign content publication.
此字段由 CMS 在活动内容发布时赋值。

Note / 注意： content_format: "article" is not a valid value for content_type: "campaign". Campaign pages with no form interaction should still be classified as "mixed" if editorial content is present, or reviewed for correct content_type assignment. content_format: "article" 不适用于 campaign 类型。若活动页面仅有图文而无表单，需重新确认 content_type 的赋值是否正确。

§15

Forbidden data 禁止上传数据

These must NEVER appear in any tracking payload. 以下数据严禁出现在任何追踪 payload 中。
Data 数据Reason 原因
Phone numbers 手机号PII
Email addresses 邮箱地址PII
OTP codes OTP 验证码Security
Raw user chat messages 用户原始聊天内容Privacy
Raw user search queries 用户原始搜索词PII risk
button_id, button_textHigh cardinality / multi-language pollution高基数 / 多语言污染

search_topic and question_topic must always be AI-classified topic labels, never raw input strings.search_topic 和 question_topic 必须是 AI 分类后的主题标签，严禁传入用户原始输入。
