02

系统架构与职责边界System Architecture

Pulse 是整个数据流水线的最上游采集层。输出数据直接进入 BigQuery，不进入任何应用系统。Pulse is the most upstream collection layer. Output goes directly to BigQuery, not into any application system.
1
群聊消息Chat Messages WhatsApp / Telegram
用户在 WhatsApp 或 Telegram 群中发送的消息文本。Pulse 监控这些群并实时接收消息。Text messages sent in WhatsApp or Telegram groups. Pulse monitors these groups and receives messages in real time.
2
Pulse 信号提取Pulse Signal Extraction This Document
关键词匹配 → 信号计数 → 活跃度统计 → 双层输出字段。每日产出一条 member-level 宽表记录，包含过去 30 天的所有字段。Keyword matching → signal counting → activity aggregation → two-layer output. Produces one member-level wide-table record daily covering the past 30 days.
3
BigQuery + 数据中台Data Platform
Pulse 每日 push 宽表数据到 BQ。数据中台负责存储、清洗、feature 计算，并向下游提供标准化数据接口。BQ 不需要存储原始消息文本。Pulse pushes wide-table data to BQ daily. The data platform handles storage, cleaning, and feature computation. BQ does not need to store raw message text.
4
Audience Gallery 系统System
独立系统。自行做聚合、规则判断、feature engineering，通过 Tag 工厂产出 Gallery tag。Pulse 不直接与 Audience Gallery 交互。An independent system that performs its own aggregation, rule evaluation, and feature engineering to produce Gallery tags. Pulse does not interact with Audience Gallery directly.
数据流向：群聊消息 → Pulse → BigQuery → 数据中台 → Audience Gallery → Gallery Tags。每一层职责明确隔离，Pulse 只关心"采集正确"。Data flow: Chat messages → Pulse → BigQuery → Data Platform → Audience Gallery → Gallery Tags. Each layer has clear, isolated responsibilities. Pulse only cares about "collecting correctly".

05

输出设计：双层信号模型Output Design: Two-Layer Signal Model

Pulse 输出两层数据，解决两个不同的需求：Layer A 给工程团队理解和调试；Layer B 给下游系统精准消费。Pulse outputs two layers: Layer A for engineering understanding and debugging; Layer B for precise downstream consumption.
每条消息的处理逻辑：扫描消息文本 → phrase 优先匹配关键词词典（exact 兜底）→ 每个 signal_name 最多计 1 次（消息级去重）→ Layer A 对应 category +1，Layer B 对应 signal_name +1。Per-message logic: Scan text → phrase-first keyword matching (exact fallback) → each signal_name counts at most once per message → Layer A category +1, Layer B signal_name +1.

供 Audience Gallery / 数据中台精准消费For precise consumption by Audience Gallery / data platform
