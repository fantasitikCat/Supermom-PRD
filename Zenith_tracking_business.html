Q3

Which channel brings the best users?

哪个渠道带来的用户质量最高？

We don't just count clicks from each channel — we measure the quality of those users, all the way through to a completed booking. Some channels bring lots of visitors who mostly leave right away; others bring fewer people, but most of them go on to book.

我们不只看每个渠道带来多少流量，更看这些流量最终能走到预约成功的质量。有的渠道带来很多人但大多数直接离开；有的渠道带来的人少，但大多数都走到了预约成功。

⚠️
This report depends on the marketing/media team, not the tech team.
We identify which channel a user came from by reading the UTM parameters in the promotional link URL — for example utm_source=meta or utm_source=tiktok, with utm_content identifying the specific ad/creative. These parameters must be added to every promotional link by the team running the campaign before it goes live.

If UTM parameters are missing or inconsistently named, we cannot tell channels apart and all traffic will appear as having no attributed source — making channel analysis impossible. This is not something the tech team can fix after the fact — the tech side only reads whatever is already on the URL, it cannot generate or backfill these values.

✅  Action required: Please confirm with the campaign/media team that all promotional links have correct and consistent utm_source / utm_content parameters before launch.
这份报告的数据质量由投放/媒介团队决定，不是技术团队能控制的。
我们识别用户来自哪个渠道，是通过读取推广链接 URL 里的 UTM 参数——例如 utm_source=meta 或 utm_source=tiktok，具体广告素材由 utm_content 标识。这些参数需要由负责投放的团队在活动上线前加到每一条推广链接上。

如果 UTM 参数缺失或命名不统一，我们就无法区分渠道，所有流量都会显示为"无归因来源"，渠道分析将无法进行。这是技术团队事后无法修复的问题——技术侧只是被动读取 URL 上已有的参数，无法替业务生成或补全这个值。

✅  需要确认：请在活动上线前，与投放/媒介团队确认所有推广链接已正确且统一地加上 utm_source / utm_content 参数。

Q4

What course level are most of our users recommended?

我们的用户大多数被推荐哪种课程等级？

Every user who completes the assessment gets assigned a course level and a recommended course. We track only the classification result — not the raw answers to each question, since the detailed answers are already saved directly to our database as part of the normal submission flow.

每个完成测评的用户都会被分配一个课程等级和推荐课程。我们只追踪分类结果——不追踪每道题的具体作答内容，因为详细的作答内容已经随正常提交流程直接存入数据库。

Q5

Do new users and existing users behave differently?

新用户和老用户的表现有差异吗？

All users go through phone verification when booking. At that moment, the system identifies whether the person is a brand new user or an existing account. We attach this to the booking events — so every conversion is tagged with new or existing user status.

所有用户预约时都要经过手机验证，系统在这一步会识别用户是全新用户还是已有账号的老用户。我们把这个信息带入预约相关事件——所以每一个转化都带有新老用户标签。

ℹ️
How we know: During OTP verification, the backend returns whether the phone number is new to the system. This is passed through as user_status = new_user or existing_user — no extra steps needed from the user.
判断方式：OTP 验证时，后端会返回该手机号是否为系统新号码。前端将此信息以 user_status = new_user 或 existing_user 的形式透传，用户无感知。
