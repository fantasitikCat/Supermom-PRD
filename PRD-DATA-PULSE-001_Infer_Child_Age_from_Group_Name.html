PRD · Data · Pulse Enrichment

Pulse EDD → 孩子年龄推断 Pulse EDD → Child Age Inference

Pulse 通过 LLM 识别群名中的 EDD，计算估算月龄并映射至统一年龄枚举，输出至 BigQuery；Gallery 可直接消费枚举，也可基于月龄自定义映射规则。 Pulse uses LLM to detect EDD signals in group names, computes estimated child age in months, maps to a standard age enum, and writes results to BigQuery. Gallery can consume the enum directly or apply its own mapping rules based on the raw month value.

§1

背景Background

Pulse 能识别用户所属的 EDD Group，例如 EDD = Nov 2025、EDD = Jan 2026。Gallery 希望支持按照孩子年龄段进行用户圈选，但无法直接从 EDD Group 推断孩子年龄，因此需要由 Pulse 负责年龄推断并输出统一的年龄枚举。 Pulse can identify which EDD groups a user belongs to — e.g. EDD = Nov 2025, EDD = Jan 2026. Gallery needs to support user segmentation by child age range, but cannot directly infer child age from EDD groups. Pulse will handle the inference and output a standardized age enum.

Gallery 希望支持的圈选年龄段包括：0–3 months、4–6 months、7–12 months、1–3 years、4–6 years、12 years+，以及 prenatal（孩子尚未出生）。 Gallery's target age segments are: 0–3 months, 4–6 months, 7–12 months, 1–3 years, 4–6 years, 12 years+, and prenatal (child not yet born).

为什么由 Pulse 处理？Why handled by Pulse? Pulse 已接入 Vertex AI / Gemini 2.5 Flash，LLM pipeline 已就绪，复用成本低。Pulse 输出预计算结果，减少 Gallery 侧的计算负担；Gallery 如有自定义需求，可基于原始月龄字段自行处理。 Pulse already runs a Vertex AI / Gemini 2.5 Flash pipeline. Reuse cost is low. Pulse outputs precomputed values to reduce Gallery's computational burden; if Gallery has custom requirements, it can map from the raw month field.
§2

目标Objective

Pulse 完成从群名识别 EDD → 计算估算月龄 → 映射年龄枚举的全链路，每月定期刷新，输出结果供 Gallery 及其他下游直接消费。 Pulse owns the full pipeline: group name → EDD detection → estimated age in months → age enum mapping, refreshed monthly and available for Gallery and other downstream consumers.

§6

Pulse 推断逻辑Pulse inference logic

Step 1 · LLM 识别 EDDStep 1 · LLM EDD detection

每次调用传入一个群名，Gemini 2.5 Flash 判断是否含 EDD 信号并提取年月。仅返回合法 JSON，不得有前缀文字。 Each call passes one group name to Gemini 2.5 Flash. The model determines whether an EDD signal exists and extracts year and month. Returns valid JSON only — no preamble.

LLM Output Schema Pulse · Gemini 2.5 Flash 
{
  "has_edd":    boolean,
  "edd_year":   number | null,
  "edd_month":  number | null,        // 1–12
  "confidence": "high" | "medium" | "low" | null
}

Rules:
  - Return has_edd: false when uncertain (never guess)
  - If confidence is "low", set has_edd: false
  - Only write to BQ when confidence is "high" or "medium"
Step 2 · 计算估算月龄Step 2 · Compute estimated age in months
Formula 按月估算，无具体日期Month-level estimate, no exact date 
estimated_child_age_month =
    (current_year - edd_year) * 12
  + (current_month - edd_month)

Example:
  current_month = 2026-06
  EDD           = 2025-11
  result        = (2026-2025)*12 + (6-11) = 12 - 5 = 7 months

Prenatal example:
  current_month = 2026-06
  EDD           = 2026-09
  result        = (2026-2026)*12 + (6-9) = -3 months  → prenatal

§8

更新机制Refresh mechanism

由于孩子年龄随时间变化，Pulse 需要定期重新计算月龄和枚举值。 Since child age changes over time, Pulse must periodically recompute age months and enum values.

LLM 解析是否每月重跑？Does LLM parsing re-run monthly?
建议：LLM 仅在群名新增或变更时触发，不随月度刷新重跑（群名不变则 edd_year/edd_month 不变）。月度刷新仅重新计算月龄和枚举。Recommended: LLM only runs when a group name is added or changed, not on every monthly refresh (group name unchanged → edd_year/edd_month unchanged). Monthly refresh only recomputes age months and enum.
