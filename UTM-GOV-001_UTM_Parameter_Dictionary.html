Who Owns What 谁负责什么

谁负责什么

UTM parameters have two types of owners — Definition owners who decide what values are allowed, and Execution owners who implement them in systems. These are different responsibilities.

UTM 参数有两种负责人——定义负责人决定允许哪些值，执行负责人在系统中实现。两者职责不同。

For CRM / Aima CRM / Aima 场景
utm_term = {rec_id} — When Aima sends a recommendation, utm_term carries the rec_id from the Recommendation Engine. Marketing has confirmed they no longer use utm_term for offer categories. This field is now reserved for rec_id in CRM/Aima channels. utm_term = {rec_id} — 当 Aima 发送推荐时，utm_term 携带推荐引擎提供的 rec_id。Marketing 已确认不再使用 utm_term 放活动品类。此字段在 CRM/Aima 渠道中现在专门用于 rec_id。
When empty 为空时 If no rec_id is available (no Recommendation Engine involvement), utm_term is omitted from the link. 如果没有 rec_id（无推荐引擎介入），utm_term 从链接中省略。

Override Rules 覆盖规则

覆盖规则

When a business user manually adds UTM parameters to a base URL before submitting to a system, the following rules apply.

当业务用户在将链接提交给系统之前手动添加 UTM 参数时，适用以下规则。

Parameter参数Business adds manually业务手动添加System behaviour系统行为
utm_sourceutm_sourceAny value任意值🚫 System overrides with correct value. Logs warning.🚫 系统用正确值覆盖。记录 warning。
utm_mediumutm_mediumAny value任意值🚫 System overrides with correct value. Logs warning.🚫 系统用正确值覆盖。记录 warning。
utm_campaignutm_campaignCampaign name / ID活动名称 / ID✅ Accepted. System uses business-provided value unless a flow_name is available (flow_name takes priority).✅ 接受。系统使用业务提供的值，除非有 flow_name（flow_name 优先）。
utm_contentutm_contentCTA variantCTA 变体✅ Accepted. Business value used as-is.✅ 接受。直接使用业务提供的值。
utm_termutm_termAny value任意值✅ System sets utm_term={rec_id} for CRM/Aima channels. Business-supplied utm_term overridden.✅ 系统为 CRM/Aima 渠道设置 utm_term={rec_id}。覆盖业务手动填写的 utm_term。
